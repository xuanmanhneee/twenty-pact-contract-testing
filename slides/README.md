# Slide thuyết trình (Slidev)

Nội dung ở `slides.md`. Số liệu lấy từ `docs/testing.md` và `logs/` (lượt chạy 21/11/2026).

```bash
cd slides
npm install
npm run dev      # xem và trình chiếu tại http://localhost:3030
npm run build    # sinh bản web tĩnh vào dist/
```

Còn chờ: slide "Đóng góp và lịch sử commit" (cập nhật sau peer review), sơ đồ kiến trúc của Luyến (chèn vào slide "Hệ thống và phạm vi").
